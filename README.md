# PCOS Education Website

Static responsive website developed from the supplied PCOS write-up.

## Navigation
Home | PCOS | PCOS to PMOS | Symptoms | Symptom Awareness | FAQ | Resources

## Technologies
HTML5, CSS3 and vanilla JavaScript.

## Run
Open `index.html` in a browser.

## GitHub Pages
Upload the project to a repository, then use Settings → Pages → Deploy from a branch → main → /(root).

## Notice
For health education and awareness only; it does not provide diagnosis or replace professional medical advice.
